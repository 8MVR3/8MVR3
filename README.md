### 🎓 Исследования и достижения

- **Магистерская работа (МФТИ, 2026, «отлично»):** автоматический промптинг мультимодальных моделей Qwen-VL для генерации обучающих аэрофотоснимков. Детектор YOLO11m на смеси синтетических и реальных данных почти вдвое точнее: mAP@50 вырос с 0,48 до 0,92.
- **Бакалаврская работа (МАИ, 2024, «отлично»):** распознавание объектов с ориентированными рамками на аэрофотоснимках.
- 🥇 **1 место на хакатоне Ростелекома (МФТИ):** приложение на Flask и ClickHouse для анализа и визуализации логов веб-серверов.
